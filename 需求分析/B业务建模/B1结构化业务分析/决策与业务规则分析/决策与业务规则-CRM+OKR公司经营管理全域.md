### 4.4 自动退回优先级

同一线索同时满足多个退回条件时，以最先达到的条件执行一次退回并记录全部命中原因：

1. 抢领/分配后2个工作日未首次有效跟进。
2. 连续7个工作日无有效跟进。
3. 30天保护期或经批准的延长期届满。
4. 当前负责人主动释放。

### 8.2 综合评分计算

默认计算公式：

`综合评分 = 岗位KPI得分 × 60% + OKR得分 × 30% + 项目及跨部门协作得分 × 10%`

使用部门自定义权重时：

`综合评分 = Σ（各评分项得分 × 对应生效权重）`

计算约束：

1. 所有参与计算的权重合计必须为100%。
2. 客观业务数据支撑的评分项权重合计不得低于50%。
3. 缺少必要证据的评分项不得直接按满分计入，应退回补充或按生效规则处理。
4. 重复引用同一成果时，只保留一个有效计分归属。
5. 一票否决完成确认后，发放系数为0；综合评分仍保留用于解释和申诉。

### 8.3 发放系数决策表

| 综合评分S | 默认发放系数C |
|---|---:|
| S ≥ 100 | 1.2 |
| 90 ≤ S ＜ 100 | 1.1 |
| 80 ≤ S ＜ 90 | 1.0 |
| 70 ≤ S ＜ 80 | 0.8 |
| 60 ≤ S ＜ 70 | 0.6 |
| S ＜ 60 | 0 |

工资影响公式：

`实发绩效工资或奖金 = 绩效工资基数 × 发放系数C`

补充约束：

- 发放系数默认上限为1.2，可由综合管理部按规则版本配置。
- 固定工资金额不进入上述乘法，不因综合评分减少或增加。
- 一票否决经确认后，发放系数取0；若申诉改变结论，按最终锁定结果重新计算。
