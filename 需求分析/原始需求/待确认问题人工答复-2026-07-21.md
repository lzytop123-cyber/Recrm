## Q-A1-002

线索查重优先手机号，其次为公司名称或客户名称；手机号相同则合并。公司名称相同情况下的合并规则原文存在歧义，需要再次确认。保护期 30 天。董事会拥有最高查看权限并可设置查看、分配权限。个人可查看自己录入的线索和公司分配给自己的线索。每天规定时间开放线索抢领，类似抢单；所有人都可以领取，领取成功者负责跟进；超期退回线索池。

## Q-A1-003

财务覆盖合同记录和收款管理；财务部负责人覆盖审批、开票、退款、成本、利润及核验等全流程，具体细分权限由财务部负责人分配。

## Q-A1-004

- 销售：线索获取 → 线索分配 → 线索跟进 → 需求确认 → 方案报价 → 商务谈判 → 合同签署 → 收款 → 交付；包含线索退回、线索流失分支。
- 项目交付：合同生效 → 项目立项 → 计划制定 → 任务分派 → 执行 → 风险监控 → 验收 → 交付完成 → 复盘；包含变更管理。
- OKR：目标制定 → 目标对齐 → 目标确认 → 执行跟踪 → 周期评估 → 复盘总结 → 下周期目标。
- 工单：创建 → 分派处理人 → 受理 → 处理 → 确认结果 → 关闭；包含转派、升级、重新打开。

## Q-A1-005

OKR 按月管理；公司、部门、个人的规则及评分标准人工设置，系统自动计算结果。是否逐级对齐的原文表达仍需确认。

## Q-A1-006

## Q-A1-007
