# CRM+OKR公司管理系统：需求理解确认审查稿

## 1. 审查范围

本次审查覆盖需求理解层A1至A6：需求澄清、干系人、目标与成功指标、用户场景与旅程、用户故事和范围边界。

## 2. 关键结论

1. 产品定位为单一公司内部使用的一体化经营管理系统，统一承接售前、合同资金、项目交付、日常协作、人员与会议排期、OKR绩效、员工生命周期及经营分析。
2. 主系统与线索池、AI知识库两个配套子系统使用统一账号、统一入口并保持业务数据关联。
3. 经营主链为线索与客户经营、合同与收款、分类项目交付、验收复盘及售后续约；项目、工单、排期、OKR和知识库提供执行支撑。
4. 当前形成41条用户故事，覆盖管理层、中层负责人、员工及各专业业务角色的核心价值。
5. 首期采用单一公司边界，不建设多公司管理、外部客户门户、会议室管理、完整招聘候选人管理、供应链管理及完整法定财税系统。

## 3. 已确认事实

- 线索采用全员录入、普通公共线索按权限抢领、重点客户或已筛选商机由市场销售中心分配的混合机制；每个客户保留一个主负责人。
- AI产品销售、AI定制开发和自媒体代运营采用已确认的分类交付旅程。
- OKR按月管理，公司目标到部门目标强制对齐，个人至少一项目标对齐部门；绩效结果只影响绩效工资或奖金。
- 综合管理部负责绩效规则、校准与申诉；财务负责工资核算、复核与发放；双方流程完成后发布工资条。
- 首期纳入员工入职、转岗、离职、劳动合同、档案和考勤。
- AI知识库按来源授权、最小查看权限、授权后采集、历史回溯单独审批、纠错下架及删除确认规则治理。
- 会议排期覆盖内部培训会议和外部沙龙线下产品会议，与讲师排期关联并同步飞书日历；首期不做会议室管理。
