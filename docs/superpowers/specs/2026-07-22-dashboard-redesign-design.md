# 首页经营看板改版设计

## 目标

将首页从等权卡片列表改为面向全体员工、尤其便于管理者快速阅读的经营总览。视觉采用沉稳商务风，以已确认的 A 型“左侧经营总览 + 右侧待办栏”为主体，并加入 B 型“近 6 个月回款趋势图”。

## 信息层级

1. 页首展示问候语、数据范围和刷新操作。
2. 第一视觉焦点为回款趋势：展示本月已确认回款金额及近 6 个月真实数据。
3. 第二层展示用户有权限查看的核心经营指标，优先财务、线索、客户和合同指标。
4. 下方按原业务分组保留全部可见指标，避免改版造成信息丢失。
5. 右侧固定为“待处理事项”和“快捷入口”，突出下一步行动。

## 数据约束

- 趋势图只使用当前用户数据权限范围内、状态为已确认且具有实际收款日期的记录。
- 返回包含当前月在内的连续 6 个自然月；没有回款的月份补 0，不制造估算值。
- 若用户无收款查看权限，后端返回空趋势，前端展示明确的无权限/暂无数据状态。
- 保留现有 `/api/v1/dashboard` 接口与路由，在响应中兼容性新增 `payment_trend` 字段。

## 视觉与交互

- 深海军蓝、冷灰背景和低饱和蓝作为主色；成功、警告、危险仅用于有语义的数字和状态。
- 页面占满可用内容宽度，主体与右栏采用约 3:1 比例，消除原 1200px 限宽导致的右侧空白。
- 卡片边界轻、圆角克制、阴影极弱；避免每块内容都形成同等强度的容器。
- 趋势图使用原生 SVG 绘制折线、面积和数据点，不增加图表依赖。
- 所有可点击指标、待办和快捷入口保留键盘焦点；支持 `prefers-reduced-motion`。
- 桌面端优先；在较窄窗口下右栏自然下移，内容仍可读。

## 不在范围内

- 不新增筛选器、日期切换、预测值、同比/环比等当前数据无法支持的指标。
- 不改变权限模型、导航结构、登录逻辑或其他业务页面。
- 不执行 Git 暂存、提交或分支操作。

## 验收标准

- 管理者进入首页首先看到本月回款和近 6 个月趋势，其次看到核心指标和待办。
- 全体员工只看到自己权限范围内的数据和入口。
- 原有所有可见业务指标仍能在页面中找到并可跳转。
- 后端趋势单元测试、前端结构测试和前端生产构建全部通过。
