# 模块检查与修复报告

日期：2026-09-30

已按确认范围完成局部修复：沿用现有页面风格，处理接口兼容、知识库可见性、员工离职交接、Agent 会话及确认异常，并优化加载反馈和小屏布局。KPI 计分公式、权重与等级规则没有调整。

## 已修复的缺陷

| 模块 | 缺陷及影响 | 修复结果 |
| --- | --- | --- |
| KPI 考核 | 新旧页面 API 导出、类型及路由不一致，导致页面编译失败或调用错误 | 补齐兼容接口，并按后端实际路由调用；新增当前周期切换方法 |
| KPI 考核 | 后端 actual_value 未映射到实际值，刷新后缺值；旧详情可能保留上一次状态 | 按当前服务端详情回填指标、实际值、工作说明和提交状态；真实 0 值保留 |
| KPI 考核 | “保存草稿”发送的 draft 被后端忽略，实际推进为已提交 | 草稿独立保存，不计分、不提交材料、不推进阶段，并保留版本冲突校验 |
| KPI 考核 | 清空已保存实际值或工作说明后，旧值会再次回显 | 草稿显式空值可持久化；未提供的指标保持原值，正式提交仍拒绝空实际值 |
| KPI 考核 | 历史记录没有指标明细时刷新总分被覆盖为 0；未完成指标被当作已得分 | 保留历史已有总分，含未得分指标时总分保持未完成；未改计分规则 |
| 知识库 | 普通阅读者可读取历史版本，历史草稿/已撤回内容可能被暴露 | 路由和服务双层要求管理权限；覆盖不同文档状态的权限回归 |
| 知识库 | 审批兼容函数误调用提交接口，页面缺少必要类型和常量 | 修正 approve 路由，恢复页面需要的接口契约 |
| 员工管理 | 携带未变化角色编辑本人资料被误拦截；通过离职状态能绕过禁止停用本人的校验 | 未变化角色允许正常编辑，角色变化仍受限制；本人离职停用路径也受保护 |
| 员工管理 | 调岗、离职操作模拟成功；离职交接页使用演示数据及虚构员工 ID | 接入真实调岗、离职、交接 API，使用数字员工 ID；请求成功后才显示成功，失败保留服务器状态 |
| 离职交接 | 可将业务转交给本人、禁用或离职员工；完成后仍能改交接单 | 增加接收人和交接状态校验 |
| 离职交接 | 资产已真实归还，历史资产快照仍阻止交接完成 | 以当前持有资产为准；未归还资产仍阻止完成，移除前端模拟归还 |
| Agent | 确认事件 type 被对象展开覆盖，前端不弹确认 | 固定 SSE 协议类型并兼容旧请求类型 |
| Agent | 一次包含多项写操作时只展示第一项，却可能执行全部 | 确认窗口列出全部待执行写操作；取消跳过全部写操作 |
| Agent | 新会话后旧流/历史请求回写；确认失败后丢失待确认动作 | 中止旧流并隔离迟到回调；失败保留确认项，待确认时阻止新消息 |
| Agent | 流请求写死 localhost，不适用于其他设备访问；异常信息直接暴露 | 使用同源 API 代理；禁用账号重新校验，内部异常写日志，前端收到通用提示 |

## 页面优化

- 员工列表补充加载、失败及重试提示，切换筛选时迟到响应不会覆盖新结果；支持清空资料字段。
- 知识库工具栏、分页、文档内容与弹窗适配小屏。手机表格取消固定操作列，避免遮住文档标题；文档抽屉底部按钮为 Agent 悬浮入口留出空间。
- KPI 发起页面在小屏改为单列步骤与可换行工具栏，底部操作避开 Agent 悬浮入口。
- 人事工作台恢复真实离职交接入口；离职弹窗限制为视口宽度；假期余额加载失败或没有数据时不展示伪造余额。
- 为通过整站类型检查，修复了目录任务字段、人员分页结果、线索创建输入和页面回调类型。项目立项改用精简合同门禁接口，沿用 project:view 和合同本人负责/创建/管理员校验，不要求额外合同阅读权限，也不返回金额。
